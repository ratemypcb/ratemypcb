# Phase 7 — Validation Strategy

> Fast fixture-backed validation for source-linked DFM/assembly families, fail-closed qualification, inference promotion, and deterministic release-unblock policy.

## Test infrastructure

| Property | Value |
| --- | --- |
| **Framework** | Rust built-in unit/integration harness + Node built-in `node:test` |
| **Config** | Workspace `Cargo.toml`; no new test framework or dependency |
| **Focused command** | `cargo test -p ratemypcb-core --test dfm_release --locked` |
| **Existing regressions** | `cargo test -p ratemypcb-core --test fabrication_release --locked && cargo test -p ratemypcb-core --test schematic_release --locked` |
| **Report regressions** | `node --test tests/board-view.test.mjs tests/report-contract.test.mjs tests/report-ux.test.mjs` |
| **Full phase command** | `cargo fmt --all -- --check && cargo clippy --all-targets --locked -- -D warnings && cargo test --all --locked && node --test tests/board-view.test.mjs tests/report-contract.test.mjs tests/report-ux.test.mjs && git diff --check` |
| **Feedback target** | Run the focused task filter after every task and the full phase command at Plan 07-11 closure |

## Sampling rate and gates

- **Intelligent-format disposition:** Exact external receipts `06-01-SUMMARY.md` and `06-08-SUMMARY.md` record Phase 6 no-go for both ODB++ and IPC-2581 this release, FMT-03/FMT-05 complete, FMT-04 not applicable, and Phase 6 8/8. Phase 7 therefore uses native KiCad plus Gerber/X2+Excellon only; no intelligent-format integration or parity fixture is planned, and Plan 07-03 is unblocked.
- **Before Wave 4:** Plan 07-03's one bounded CLI→ReviewOptions→core authority seam must pass exact-unit/provenance/constructor checks. Threshold-dependent geometry may use only source/version-bound normalized `ManufacturingConstraint` values; construction match/conflict may use only represented normalized `ConstructionEvidence`/semantic constraints. Missing threshold authority is `not_checked`; unrepresented order/profile facts are confirmation gaps only.
- **After every task:** run its exact `<verify><automated>` command; no watch mode and no network.
- **After each family:** retain positive, hard-negative, and prerequisite-mutation targets; report TP/FP/FN/TN, precision, recall, not-checked mutations, and unsupported targets separately.
- **Before deterministic Blocking:** require defined precision at least 0.95, reported defined recall, green mutations, fixture digests, and reviewed exact family/version promotion metadata.
- **Before inference Blocking:** also require the exact family/version human approval in `07-PROMOTION-CHECKPOINT.md`; none is approved at planning time, so inference remains `EvidenceOnly`.
- **Before closure:** run the full phase command, manifest/source audit, schema equality if public DTOs changed, deterministic ordering/resource mutations, and independent plan/code review.
