## Trust Boundaries

| Boundary | Description |
| ---------- | ------------- |
| Report/assessment JSON → HTML | Untrusted text and identifiers enter a durable self-contained document |
| Assessment refs → anchor targets | Invalid or colliding refs can misdirect engineering actions |
| Core policy → viewer | Client recomputation can contradict the deterministic gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| ----------- | ---------- | ----------- | ---------- | ------------- | ----------------- |
| T-01-01 | Tampering | CLI digest/render path | high | mitigate | Exercise exact report bytes and reject digest/reference mismatch before snapshot |
| T-01-02 | Repudiation | HTML anchors | high | mitigate | Unique deterministic ids and integration assertions for every href target |
| T-01-03 | Information disclosure | `viewer::snapshot` | medium | mitigate | Preserve escaped payload, local/offline behavior, and no network calls; detailed redaction policy is Phase 8 |
| T-01-04 | Elevation of privilege | `renderReport` | critical | mitigate | Remove viewer approval/risk scoring and render only validated core/assessment decision data |
| T-01-05 | Cross-site scripting | report/assessment text | high | mitigate | Continue textContent/DOM creation and `<>&` escaping in embedded JSON/title |
| T-01-SC | Tampering | package installs | low | accept | No package installation or dependency change in this plan |

</threat_model>
