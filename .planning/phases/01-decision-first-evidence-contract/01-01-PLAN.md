<threat_model>

## Trust Boundaries

| Boundary | Description |
| ---------- | ------------- |
| Artifact/report → deterministic policy | Untrusted or incomplete evidence must not acquire authority through defaults |
| Report bytes → assessment | Assessment may reference a different digest or invented evidence |
| Canonical identity input → public finding ID | Collision/unstable input can misbind actions and audit history |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| ----------- | ---------- | ----------- | ---------- | ------------- | ----------------- |
| T-01-01 | Tampering | `validate_assessment` | high | mitigate | Keep exact-byte digest binding and validate every verdict/action/category/question reference |
| T-01-02 | Repudiation | finding identity/provenance | high | mitigate | Canonical identity excluding prose/order plus duplicate detection and source provenance tests |
| T-01-03 | Information disclosure | serialized provenance | medium | mitigate | Store digests/locations, not source file contents or credentials; retain existing report bounds |
| T-01-04 | Elevation of privilege | `approval_eligible` and decision summary | critical | mitigate | Required missing/failed/stale/unsupported states close approval; risk cannot be reduced by absence |
| T-01-SC | Tampering | package installs | low | accept | No package installation or dependency change in this plan |

</threat_model>
